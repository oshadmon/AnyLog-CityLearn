Every community keeps its own energy data

These are real readings from a simulated neighborhood: hourly electricity use, solar output, batteries, weather and prices for each building. Each community's readings are stored on its own AnyLog node. Nothing was copied into a central database.

Asking the network what it holds…

What is AnyLog? A network of nodes that each keep their own data where it was produced, yet answer questions together as if they were one database. Here, each node stands for one community's utility or building operator.

Ask for a building by name, not by location

You don't need to know which node holds a building's data. Pick one, and watch how AnyLog finds it and fetches it.

What is the UNS? The Unified Namespace is a shared directory of names, like a phone book for data. Each name, such as a building, points to where its readings are stored. Programs ask by name, so they keep working when data moves or new sites join.
